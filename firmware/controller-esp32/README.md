# ESP32 Controller Firmware

This directory contains the firmware for the ESP32-based syringe pump controller.

## Current Version: v4.5.5

The latest firmware version (v4.5.5) includes:
- Enhanced microstepping options (1/8, 1/16, 1/32, 1/64, 1/256)
- USB serial control interface
- Physical keypad and LCD interface
- Support for up to 4 independent syringe pumps
- Persistent settings storage
- Enhanced safety features with input validation

## Directory Structure

- `syringe_pump_v4.5.5/` - Latest firmware version
- `syringe_pump_v4.5.4/` - Previous version
- `syringe_pump_v4.5.3/` - Previous version  
- `syringe_pump_v4.5/` - Earlier version
- `syringe_pump_v4.4/` - Earlier version
- `syringe_pump_v4.3/` - Earlier version
- `dev-info/` - Development information and libraries
